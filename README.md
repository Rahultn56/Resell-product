# ♻️ ReMarket - Used Products Marketplace (Resell-product)

A clean, responsive marketplace web application for buying and selling used goods. Browse pre-owned electronics, furniture, vehicles, books, and fashion with smart filters, live search, favorites, and seller direct contact.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FRahultn56%2FResell-product)

---

## 🌟 Key Features
- **Categorized Discovery**: Browse items across Electronics, Furniture, Vehicles, Books, Fashion, and more.
- **Advanced Filtering**: Filter by category and maximum price range (₹5,000, ₹10,000, ₹25,000, Any).
- **Instant Search**: Real-time title and description search.
- **Favorites & Wishlist**: Save favorite items with persistent local storage.
- **Sell Product Listing**: Dedicated listing form to publish new used items with seller contact details.
- **Product Detail Modal**: High-res image display, full item specifications, seller info, and direct phone contact button.
- **Responsive Design**: Fast and touch-friendly interface across mobile, tablet, and desktop viewports.
- **100% Vercel Ready**: Preconfigured with `vercel.json` for zero-config global edge deployment.
